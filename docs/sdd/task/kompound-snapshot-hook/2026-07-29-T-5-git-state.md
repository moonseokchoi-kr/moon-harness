## 완료 조건
- [ ] **dirty 판정**: `git status --porcelain`(kompound_repo에서 실행)이 비어있지 않으면 중단 신호(`precondition_failed`류) + dirty 파일 목록을 구조화된 dict로 반환. **`fetch`/`pull`/`push`는 절대 호출하지 않는다**(F13 네트워크 무호출과의 양립, §6.4).
- [ ] **divergence 판정**: `git rev-list --left-right --count @{upstream}...HEAD`로 `ahead`/`behind`를 계산(fetch 없이, 마지막으로 알려진 remote ref 기준). `behind > 0`이면 중단. `ahead > 0, behind == 0`이면 정상(미push 로컬 커밋 허용). `upstream` 미설정이면 정상(로컬 전용 저장소 — 테스트 fixture 포함, 실패로 취급하지 않는다).
- [ ] dirty 시뮬레이션 fixture에서 실행 결과가 "커밋 0건 + 중단 사유에 dirty 파일 목록 포함"임을 검증하는 테스트가 있다(spec F9 Acceptance 그대로).
- [ ] **커밋 함수** — (i) raw 전용 커밋(`snapshot(raw): N new, M updated` 형태 메시지)과 (ii) 카탈로그 전용 커밋(`snapshot(catalog): ...`)을 **독립적으로** 수행할 수 있는 별도 함수(또는 동일 함수의 스코프 파라미터)로 제공한다 — T-10(`apply.py`)이 이 둘을 각각 호출한다(§6.3.0의 2단 커밋 경계).
- [ ] 커밋 성공 시 결과에 `{"committed": bool, "commit": "<sha|null>"}`을 반환.
- [ ] **배타 락**: `os.open(<kompound>/.git/kompound-snapshot.lock, O_CREAT|O_EXCL)`로 획득. 획득 실패 시 `busy` 신호. **stale 락(mtime > 10분)은 무시하고 인수한다.** 락 해제(release) 함수도 제공한다.
- [ ] 모든 함수는 예외를 밖으로 던지지 않고 구조화된 결과 dict(`{"ok": bool, ...}`)를 반환한다(F13 fail-safe).
- [ ] 네트워크 호출이 없음을 `no_network` fixture(`tests/conftest.py` 기존)로 물리적으로 보장하는 테스트가 있다.
